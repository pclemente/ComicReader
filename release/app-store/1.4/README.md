app bundle and existing €9.99 one-time Plus product. iCloud synchronization
remains free. The release includes Smart Queues and clearer Plus discovery.

are **Waiting for Review**, verified in App Store Connect. Automatic release
after approval is selected; the new version is not publicly available yet.
