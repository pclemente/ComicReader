# Opening comics on Mac

ComicReader 1.6 can read a supported comic directly from Finder. Choose
**Open With → ComicReader**, or use **File → Open Comic…** / **Command-O** inside the app.
PDF, CBZ/ZIP and classic CBR/RAR files are supported by the reader. Encrypted,
corrupt or unsupported archives may not open.

To make ComicReader the default for a format, select one of those files in
Finder, choose **Get Info**, select **ComicReader** under **Open with**, then
choose **Change All**. macOS asks you to confirm the choice for that format.
ComicReader does not change file associations automatically.

Direct reading is free and leaves the original file unchanged in its existing
folder. Finder Open With reads that original with temporary read access.
File → Open Comic uses a temporary reading copy from the system picker, kept
outside the library and removed when closed. Neither path adds the comic to
the library or uploads it to iCloud. Reading progress for a direct session is
not retained after closing.

Choose **Add to Library** in the reader when you want to keep the comic in
ComicReader. This free action copies the file into the library. Once the copy is
indexed, it uses normal library reading progress and the app's existing iCloud
sync preference. Turning on sync uploads library comics and their reading state
to the user's personal iCloud storage; opening a file directly does not opt in.

Plus is optional. The same one-time upgrade supplies comic text search and
quotes, reading lists, bookmarks, filters and the website download-to-library
workflow on iPhone, iPad and Mac. Finder opening, ordinary imports, reading and
iCloud sync do not require Plus.
