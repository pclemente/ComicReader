How to open a CBZ or CBR comic

Leave the file zipped. ComicReader reads your own CBZ, classic CBR and PDF files for free.

iPhone or iPadMacFile won’t open?

Try a sample: Little Nemo

If you don’t have a comic yet, start with three original Little Nemo newspaper pages by Winsor McCay, published in English in 1905.

Download the Little Nemo comic (CBZ)

Save the file to Downloads. On iPhone or iPad, import it from Files. On Mac, open it from Finder.

On iPhone or iPad

  1. In ComicReader, tap Add Comics in the empty library. If you already have comics, open Settings → Add Files in ComicReader.
  2. In the Files picker, browse to your comic. If you downloaded it in a browser, look in Downloads. Select the file to import a copy.
  3. When its cover appears in the library, tap it to read. Close the comic and open it again to pick up on the same page.

On Mac

In Finder, Control-click the file and choose Open With → ComicReader. You can also press ⌘O in ComicReader and choose a file.

Just looking? Close the comic when you’re done; the original stays where it is. To save your page for next time, choose Add to Library in the reader. The library copy can also sync for free if you turn on iCloud.

If the file won’t open

CBZ is a ZIP archive of page images; CBR is a RAR archive. ComicReader supports classic RAR, but not RAR5 or password-protected archives. Changing a filename from .cbr to .cbz won’t convert it. If the publisher offers a CBZ or PDF edition, try that copy.

If the file is in a cloud folder and won’t import, download it fully in Files or Finder and try again.

In the reader, open the text tool and choose This Page to copy any lettering it recognises for free. With ComicReader Plus, an optional one-time purchase, you can search for recognised words across a comic in your library.
