# Little Nemo sample comic

[Download the three-page CBZ](little-nemo.cbz). These are three English-language newspaper pages from *Little Nemo in Slumberland*, drawn by Winsor McCay in 1905. The artwork is in the public domain. The download is optional and separate from the ComicReader app.

| Page | Original scan |
| --- | --- |
| October 22, 1905 | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Little_Nemo_in_Slumberland_(1905-10-22).jpeg) |
| November 5, 1905 | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Little_Nemo_1905-11-05.jpg) |
| December 3, 1905 | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Little_Nemo_1905-12-03.jpg) |

The archive contains only the three JPEGs, in date order. They are exact copies of `page-04.jpg`, `page-01.jpg`, and `page-02.jpg` in the repository's [approved scan sources](https://github.com/pclemente/ComicReader/tree/main/release/app-store/sample-comics).
