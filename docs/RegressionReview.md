# ComicReader regression and iOS 27 review

The reference implementation is `swisspol/ComicFlow` at commit `05a30aea4ea757a5b82c81292e7f9fe27c5cb146`. The review covers the app controllers, library/indexer, archive/image readers, embedded uploader/WebDAV server, launch configuration, and the fork's modernization commits.

## Compatibility

- Build with Xcode 27 and the iOS 27 SDK. The deployment target is iPadOS 15 or later, the oldest version accepted by this Xcode toolchain.
- A single `UIWindowScene` owns the library and its overlays. Scene transitions save reading state, handle incoming document URLs, and rescan files added while the app was in the background.
- WebP uses Apple's ImageIO decoder. The obsolete precompiled `libwebp.a` is no longer linked, allowing native Apple Silicon simulator builds.
- The bundled UnRAR reader is compiled without its AES, SHA-1, or legacy RAR cipher implementation. Password-protected RAR headers and entries are rejected explicitly, and the App Store encryption declaration records that the app does not use non-exempt encryption.
- Local-network and Bonjour declarations support Wi-Fi transfers. The privacy manifest declares app preferences and library file timestamps. The entitlements file no longer includes macOS-only sandbox entitlements.

## Restored behavior

- Opening a comic from another app imports it again. Imports run on a serial background queue, use security-scoped, coordinated reads, preserve the original, and avoid overwriting same-named comics. Files are copied through temporary staging paths before indexing. Comics selected from Inbox, hidden folders, or deeper folders are copied into the indexed library; existing root and collection comics are reused.
- Library scans capture each directory's modification time before enumerating it. If another import lands while a scan is running, the queued update sees the later timestamp and indexes the new file instead of treating the incomplete snapshot as current.
- Settings' Add Files action opens the system document picker, including when the web server is off.
- Library startup restores the last comic and refreshes status after leaving the reader. Reading-state fingerprints now include the local filesystem device and inode, preventing a different file with the same path, size, and modification time from inheriting the prior comic's exact page. Older saved fingerprints remain readable. Settings and reader controls adapt to safe areas and rotation.
- Build 7 presented a native Plus introduction once after the first eligible build 7 launch, for existing users upgrading and for new installations, with **View Plus** and **Not Now** actions. Build 8 replaced it with a dismissible library **What's New** banner that appears on the first build 8 launch even if the old introduction was dismissed. **Free iCloud Sync**, **Explore Plus** and **X** close actions do not block queued saved-comic resume.
- Build 8 removed purchase state from the iCloud manager and coordinator. Free sync remains gated by explicit opt-in, the consented iCloud account, container availability and library readiness, and is opened from a separate library-toolbar iCloud button.
- Build 9 keeps current-page text recognition, selection, copying and system sharing free. Embedded PDF text is preferred; image-only pages use on-device recognition. Recognition can be incomplete or incorrect for some languages, scans and stylised lettering.
- ComicReader Plus remains a non-consumable purchase for four app-specific groups: Comic Search & Quotes, Custom Reading Lists, named Page Bookmarks and renderer-only Clear Ink, Grayscale and Warm Paper Image Filters. Search indexes the current comic page by page, persists partial progress locally, can stop and resume, searches available pages case- and diacritic-insensitively in page order, and jumps to a result. There is no whole-library search.
- Saved quotes are editable before persistence, record the comic filename and page, and can be opened, edited, deleted, shared or used to return to their source page. Search caches, quotes, lists and bookmarks stay local. Saved quotes remain readable, shareable and openable after refund; quote mutations remain gated. Filters do not modify comic files, and Original is always available to restore normal rendering.
- Replacing an alert cannot let its old dismissal callback cancel the new alert. Alert callbacks can safely show another alert; old spinner fade-outs cannot hide a newer spinner.
- Existing trial/limited settings migrate to the free transfer mode described by this fork.
- Reader gestures use public recognizer references. ZIP pages with a bad CRC are rejected, partial extracts are cleaned up, non-ASCII RAR filenames decode correctly, and encrypted RARs fail before extraction.
- Web uploader and WebDAV paths are normalized and checked against the upload directory. Malformed destinations return errors, and file operations cannot remove or rename the library root. WebDAV COPY/MOVE rejects identical source/destination paths, a directory's descendants, and source ancestors before replacing any destination, preserving existing files.

## Reproduce validation

Open `ComicFlow.xcodeproj`, select the shared **ComicFlow** scheme and an iPad simulator, and run **Product → Test**. The scheme includes hosted regression tests and UI tests. Tests create disposable comic fixtures in the simulator; use a test simulator rather than a device containing a personal collection.

```sh
xcodebuild -project ComicFlow.xcodeproj -scheme ComicFlow \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build-for-testing

xcodebuild -project ComicFlow.xcodeproj -scheme ComicFlow \
  -destination 'platform=iOS Simulator,name=iPad Pro 11-inch (M5),OS=27.0' \
  -parallel-testing-enabled NO CODE_SIGNING_ALLOWED=NO test

xcodebuild -project ComicFlow.xcodeproj -scheme ComicFlow \
  -configuration Release -destination 'generic/platform=iOS' \
  CODE_SIGNING_ALLOWED=NO build
```

The host regression harnesses run on macOS without an iOS simulator:

```sh
Tests/run-network-tests.sh
Tests/run-unrar-tests.sh

xcrun swiftc -swift-version 5 Classes/CRCloudSyncModel.swift \
  Tests/CRCloudSyncModelHarness.swift -o /tmp/CRCloudSyncModelHarness
/tmp/CRCloudSyncModelHarness

xcrun swiftc -swift-version 5 -D CR_CLOUD_SYNC_TESTING \
  Classes/CRCloudSyncModel.swift Classes/CRCloudSyncManager.swift \
  Tests/CRCloudSyncManagerHostHarness.swift \
  -o /tmp/CRCloudSyncManagerHostHarness
/tmp/CRCloudSyncManagerHostHarness
```

The network harness builds the bundled Mac server framework, checks uploader/WebDAV root boundaries and malformed paths, and verifies that rejected same-path, descendant, or ancestor COPY/MOVE requests preserve fixture bytes. The UnRAR harness compiles the vendored reader with `NOCRYPT`, verifies ordinary RAR listing and extraction, rejects valid encrypted-header and encrypted-entry fixtures without producing output, and checks the executable for bundled archive crypto symbols. Both create and clean private temporary directories; the network harness does not start a listening server.

The cloud model harness checks merge ordering, exact-page state, path containment, and duplicate-name handling. The manager host harness exercises the production transfer primitives against isolated local temporary directories, including the opt-in-only access contract, byte-for-byte upload/import, corrupt or missing blob repair, cancellation, account-scoped suppression, idempotence, and same-size replacement detection. The manager and coordinator have no purchase-state input or entitlement gate. These harnesses do not exercise Apple's live iCloud service, propagation, quotas, or delivery between devices.

A successful unsigned build does not validate App Store signing or distribution. Physical-device checks should cover Files/iCloud providers, local-network permission and Bonjour discovery on Wi-Fi, and background/resume with a large personal collection.
